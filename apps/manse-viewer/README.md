# 만세력 뷰어

`packages/manseryeok` 엔진을 브라우저에서 돌리는 단일 HTML 페이지.

## 빌드

```
node apps/manse-viewer/build.mjs
```

`index.template.html` + 번들된 엔진 → `index.html` (외부 의존 없는 파일 하나).

## 설계 메모

- **계산은 전부 클라이언트에서.** 생년월일이 서버로 가지 않는다. 개인정보 처리 부담이 없고,
  그 사실 자체를 페이지에 명시해 신뢰 요소로 쓴다.
- **계산 근거를 화면에 노출한다.** 적용 절기와 절입시각, 진태양시 보정량, 표준자오선,
  서머타임 여부까지 보여준다. 서비스마다 명식이 달라 생기는 불신에 대한 대응이다.
- **자시 처리는 선택지로.** 유파에 따라 갈리는 영역이라 임의로 정하지 않는다.

# 상품 그림

파일 이름을 **상품 아이디** 그대로 둔다. 확장자는 jpg·png·webp·avif 아무거나 된다.

```
wealth-report.jpg     →  /img/products/wealth-report
reunion-report.png    →  /img/products/reunion-report
```

프롬프트는 `docs/product-images.md` 에 21개가 있다.

## 알아둘 것

- **없는 그림은 안 그린다.** 21장을 다 기다릴 필요 없이 나온 것부터 넣으면 된다.
  그림 없는 상품은 지금처럼 글자만 나오고, 빈 네모가 생기지 않는다.
- **이름이 틀리면 무시된다.** 카탈로그에 없는 이름으로 저장하면 그냥 안 붙는다.
  기동 로그에 「이름이 카탈로그와 맞지 않는 그림」으로 찍히니 거기서 확인한다.
- 목록에서는 72×96 썸네일, 상세 페이지에서는 3:4 큰 그림으로 나간다.
  원본은 세로로 길게(3:4) 뽑는 것이 맞다.

## 1. 할인 행사 상태 및 설정

| 항목 | 현재 값 |
| :--- | :--- |
| 할인 행사 이름 (`PROMO_NAME`) | **수능달 기념** |
| 기념가 적용 여부 (`PROMO_ENABLED`) | **켜짐 (수능달 기념 할인가 적용 중)** |
| 종료 일정 | **끝나는 날 없음** (`PROMO_ENABLED=false`로 직접 종료) |

| 항목 | 가격 / 금액 | 기간 / 횟수 / 적용 조건 |
| :--- | :--- | :--- |
| 월운세 (`month-report`) | **9,900원** | 이용권 기간 **30일**, 최대 **6회** 열람 |
| 오늘의 운세 (`daily-report`) | **1,900원** | 소개 보답 무료 이용권 기간 **30일**, 최대 **6회** 열람 |

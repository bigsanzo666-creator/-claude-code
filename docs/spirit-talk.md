# 신령이 직접 상담한다

## 왜 만들었나

손님이 산신령을 눌렀는데 상품 목록이 나오면, 신령은 **그냥 그림**이다.
사장님 말씀대로다 — 「홈페이지 사이트에서 말해주는 느낌이 들면 안 된다.
서로 주고받고가 되어야 한다.」

그래서 신령 판에 **주고받는 칸**을 두었다.

1. 손님이 신령을 누르면 → 신령이 **먼저** 말을 건다 (이름을 부르고, 여덟 글자를 짚는다)
2. 손님이 쓰면 → 신령이 답하고 **되묻는다**
3. 세 번 주고받으면 → 「여기서부터는 제대로 봐야 해」 하고 상품으로 넘긴다

## 신령마다 사람이 다르다

`packages/talk/src/persona.ts` 한 파일에 다 있다.

| 신령 | 말투 |
|---|---|
| 도화신령 | 또래 친구처럼. 반말은 쓰되 놀리지 않는다 |
| 월신령 | 낮고 조용하게. 슬픔을 서둘러 지우지 않는다 |
| 연신령 | 차분하게 재는 사람처럼. 먼저 센다 |
| 산신령 | 나이 든 어른이 손주에게 하듯. 「~단다」 |
| 명경신령 | 군더더기 없이. 듣기 좋은 말로 덮지 않는다 |
| **삼합신령** | 셋을 겹쳐 보는 사람처럼. 하나로 단정하지 않는다 |
| 재신령 | 장사하는 사람처럼 실하게. 숫자와 그릇 이야기 |
| 풍신령 | 먼 데를 보는 사람처럼. 때와 바람 이야기 |

말투가 같으면 신령이 여덟이 아니라 한 명이다.

## 지금은 열쇠 없이 돈다

모델 열쇠(`ANTHROPIC_API_KEY`)는 카드사 심사가 끝나야 들어온다.
**그때까지도 신령은 말을 한다.**

`packages/talk/src/scripted.ts` 가 답한다. 지어낸 말이 아니라 손님의 사주에서
실제로 나온 것(일간·신강신약·제일 두꺼운 힘·비어 있는 기운)을 쉬운 말로 바꾼 것이다.

열쇠가 들어오면 `talkModel: true` 가 되고 모델이 답한다. **대본은 그대로 남는다** —
모델이 막히거나 느릴 때 손님을 빈 화면 앞에 세워 두지 않으려면 돌아올 자리가 있어야 한다.

## 넘지 않는 선

`packages/talk/src/guard.ts`. **모델을 부르기 전에** 막는다.

| 물음 | 신령이 하는 말 |
|---|---|
| 죽고 싶어요 | 갈 곳을 알려 준다 — 자살예방상담전화 **109** |
| 암 수술 받아야 할까요 | 몸은 의사에게 |
| 언제 죽나요 | 사람의 끝은 아무도 모른다 |
| 주식 사도 되나요 | 어디에 돈을 넣으라는 말은 못 한다 |
| 소송 이길까요 | 법으로 다투는 일은 변호사에게 |

## 돈이 새지 않게

- **공짜는 세 번**까지. 한 번이면 상담이 아니고, 열 번이면 살 이유가 없어진다.
- 상담은 **값싼 모델**(`claude-sonnet-5`)로 한다. 답 한 번이 400토큰을 넘지 않는다.
- **하루 한도**가 있다. `TALK_DAILY_LIMIT`(기본 1500). 넘으면 대본으로 내려간다 —
  화면은 그대로 돈다. 광고가 잘못 터져도 하룻밤에 요금이 불어나지 않는다.

## 생년월일은 서버로 안 간다

사주 계산은 **화면에서** 한다 (만세력 조각이 이미 실려 있다). 서버로 가는 것은
계산 결과 — 「어떤 사람인가」뿐이다. 신령이 말하는 데 생년월일 자체는 필요 없다.

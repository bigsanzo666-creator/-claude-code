# 정해진 것 — 다시 묻지 않는다

사장님이 이미 정하신 것만 적는다. 정해지지 않은 것은 "미정"이라고 적고,
정해지면 그 줄을 고친다. **여기 적힌 것을 다시 여쭙지 않는다.**

## 값

| 상품 | 값 | 비고 |
|---|---|---|
| 오늘의 운세 | 1,900원 | 미끼 상품 |
| 명절 가족운세 | 25,900원 | 오픈 할인 + 명절 할인 |
| 명절 가족운세 정상가 | 39,900원 | 9월 28일부터 |

- 명절 가족운세는 **넷까지** 궁합을 본다. 넷이 안 되면 그대로.
- **다섯째부터 한 명당 1만원**. 최대 여섯.
- 값은 `packages/commerce/src/catalog.ts` 한 곳에서만 온다.

## 화면 규칙

- **값은 맨 아래에만.** 위에 먼저 적지 않는다.
- **취소선 그은 정가를 쓰지 않는다.** 판 적 없는 값은 거짓 광고다.
- **상세페이지** = 손님이 결제하기 **전에**, 자기 정보를 넣고 미리 보는 화면.
  중요한 부분은 가려 둔다. (결제 후 리포트를 말하는 게 아니다.)
- 큰 글씨는 쉬운 말, 옆 작은 글씨로 명리 용어 한 줄 뜻.

## 그림·글씨

- **수묵화 화풍 금지.**
- 글씨체는 송명체 · 프리텐다드.

## 친구 추천 (2026-09-26 확정)

**소개받아 들어온 손님** — 3,000원 할인권. **2만원 이상 결제할 때만** 쓸 수 있다.

**「소개 1명」으로 치는 기준** — 소개받은 사람이 **2만원 이상** 결제했을 때만 1명이다.

| 소개 | 드리는 것 |
|---|---|
| 1명 | 오늘의 운세 30일 무료 |
| 3명 | 이번 주 행운의 번호 |
| 5명 | 월운세 6달 무료 |
| 7명 | 5만원 아래 점사 하나 무료 |
| 10명 | 신년운세 무료 |
| 15명 | 택일 **또는** 작명 중 하나 무료 |
| 20명 | 오늘의 운세·월운세·신년운세 **1년치** + 태길 1회 + 작명 1회 |

- 20명은 **평생이 아니다. 1년이다.**
- 「로또」가 아니라 **행운의 번호**다. 화면에 「로또」라는 글자를 쓰지 않는다.

## 월운세 (2026-09-26 확정)

- 값 **9,900원**
- 들어가는 것: 이번 달 전체 흐름 / 돈·일·사람 셋 / 좋은 날 셋과 조심할 날 셋 /
  이번 달에 하면 좋은 일 하나

## 행운의 번호 (2026-09-26 확정)

- 오행의 숫자(목 3·8, 화 2·7, 토 5·10, 금 4·9, 수 1·6)에서 손님에게 이로운
  기운을 골라, 그 주의 날 기운을 섞어 1~45 중 여섯 개를 뽑는다.
- **어느 기운에서 나온 번호인지 반드시 같이 적는다.**
- 「로또」·「복권」·「당첨」이라는 말을 쓰지 않는다. 사면 된다고도 하지 않는다.

## 상품 이름과 내용 (2026-09-27 확정)

- **매력 삼합 → 「내 매력, 어디서 나오는가」**
  - 사진(얼굴·손)을 받지 않는다. **사주만** 본다
  - 값은 24,900원 그대로
  - 관상·손금 이야기를 한 줄도 넣지 않는다
- **「삼합 리포트」는 이름 그대로 둔다** (헷갈릴 상대가 없어졌다)
- **사진을 받는 상품은 넷뿐이다** — 삼합 리포트 / 얼굴과 손 /
  타고난 것과 살아온 것 / 속과 겉

## 화면 말투 (2026-09-27 확정)

- **「맛보기」라는 말을 쓰지 않는다.** 파는 물건이 싸구려로 들린다
- 실제 글 보여주는 칸 제목 → **「신령이 이렇게 말합니다」**
- **「이건 안 보셔도 됩니다」 → 「이런 분께는 권하지 않습니다」**
  (흐리게 보면 「이것만 보셔도 됩니다」로 읽힌다)
- **남의 회사 이름을 쓰지 않는다.** GPT → **AI**
- 「늘봄이 다른 점」은 작은 딱지가 아니라 **제목 크기**로

## 글씨 (2026-09-27 확정)

- **본문·작은 글씨에 명조체를 쓰지 않는다.** 어두운 바탕에서 번진다.
  명조체는 큰 제목(24px 이상)에만
- **12px 이하 글씨를 한 곳도 두지 않는다**
- 얇은 굵기(200·300) 금지. 최소 400
- 그림 위에 얹힌 글씨는 뒤에 어두운 판을 깐다

## 결제로 가는 길 (2026-09-27 확정)

- **상세페이지 아래에 값을 적지 않는다.** 단추 하나만 둔다
  → **「더욱 자세한 내용 받기」**. 값은 결제 화면에서 처음 보인다
- **결제 화면에 손님 정보가 이미 채워져 있어야 한다**
  (성함·생년월일·성별·태어난 시간·태어난 곳)
  다시 묻는 순간 손님이 귀찮아서 나간다
- **사진은 결제 화면에서 받는다.** 휴대폰이면 카메라를 그 자리에서 연다.
  사진을 안 올리면 결제 단추를 막는다
  (「사진 없이 결제하면 반쪽만 나간다」는 구조를 없앴다)

## 그림 (2026-09-27 확정)

- 글자만 있는 자리에 **조선시대 풍 그림**을 함께 둔다. 장수는 상관없다
- 넣을 곳 — 「이런 분이 보시면 좋습니다」 세 줄 / 1층~4층 /
  그 밑 네 줄 / 「그래서 믿어도 되는가」 비교 칸
- **그림 안에 글자를 넣지 않는다**

## 만들기로 한 새 상품 — 결혼 택일 (2026-09-27 메모)

「양가 일정 때문에 기준이 필요할 때」에서 나온 것. **혼인 날짜를 골라 주는 상품.**

- 지금 파는 **「결혼 시기」(24,900원)는 「몇 년쯤」**이고, 이것은 **「며칠」**이다. 다른 물건이다.
- 값은 **제왕절개 택일(59,000원)** 언저리. 예식장 잡기 전에 보는 것이라 돈을 낸다.
- **지금 택일 계산을 그대로 못 쓴다.** 제왕절개 택일은 *아기의 여덟 글자를 짓는*
  계산이고, 혼인 택일은 *신랑·신부 두 사람의 글자에 그 날이 부딪히는지*를 보는
  계산이다. 새로 짜야 한다.
- 다만 바탕은 다 있다 — 만세력, 충·형 판정, 궁합. 표(생기복덕·황도길일·손 없는 날)만
  새로 넣으면 된다.
- 표가 유파마다 다르다. **어느 표를 썼는지 리포트에 적는다.**
- 받을 것 — 신랑·신부 생년월일시, 원하는 기간(예: 내년 봄), 피해야 할 날.

## 나중에 할 것 — 문서 신령 들이기 (2026-09-27 메모)

재신령이 상품 **여섯**을 맡아 제일 많다. 그런데 그중 **넷이 문서·공부**다
(시험 합격운·진학운·취업운·공부문서운). 돈은 둘(돈그릇·출세운)뿐이다.

곳간은 돈 창고인데 거기서 수능 이야기를 하니 **그림도 말도 어색하다.**
당장은 그림 배경만 「문서 곳간」으로 바꿔 막아 두었다.

**신년 지나고 문서·공부를 맡을 신령을 하나 들인다.** 그러면 재신령 둘,
문서신령 넷으로 갈라져 수도 고르고 말도 맞는다.
지금 하면 얼굴 그림·영상·터까지 새로 만들어야 해서 성수기를 놓친다.

## 일하는 법

- 코드는 **안티그라비티**가 짠다. 나는 지시문을 쓰고 검수한다.
- 사장님께는 **파일로 드리지 않는다.** 대화창에 통째로 적어 드린다.
- 사장님이 고칠 것을 알려주시면 **그냥 고친다.** 왜 그랬는지는 묻지 않으면 안 적는다.
- **결제 테스트는 맨 마지막에 한 번.**

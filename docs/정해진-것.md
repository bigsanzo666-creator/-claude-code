# 정해진 것 — 다시 묻지 않는다

사장님이 이미 정하신 것만 적는다. 정해지지 않은 것은 "미정"이라고 적고,
정해지면 그 줄을 고친다. **여기 적힌 것을 다시 여쭙지 않는다.**

## 값

| 상품 | 값 | 비고 |
|---|---|---|
| 오늘의 운세 | 1,900원 | 미끼 상품 |
| 명절 가족운세 | 25,900원 | 오픈 할인 + 명절 할인 |
| 명절 가족운세 정상가 | 39,900원 | 9월 28일부터 |

- 명절 가족운세는 **넷까지** 궁합을 본다. 넷이 안 되면 그대로.
- **다섯째부터 한 명당 1만원**. 최대 여섯.
- 값은 `packages/commerce/src/catalog.ts` 한 곳에서만 온다.

## 화면 규칙

- **값은 맨 아래에만.** 위에 먼저 적지 않는다.
- **취소선 그은 정가를 쓰지 않는다.** 판 적 없는 값은 거짓 광고다.
- **상세페이지** = 손님이 결제하기 **전에**, 자기 정보를 넣고 미리 보는 화면.
  중요한 부분은 가려 둔다. (결제 후 리포트를 말하는 게 아니다.)
- 큰 글씨는 쉬운 말, 옆 작은 글씨로 명리 용어 한 줄 뜻.

## 그림·글씨

- **수묵화 화풍 금지.**
- 글씨체는 송명체 · 프리텐다드.

## 친구 추천 (2026-09-26 확정)

**소개받아 들어온 손님** — 3,000원 할인권. **2만원 이상 결제할 때만** 쓸 수 있다.

**「소개 1명」으로 치는 기준** — 소개받은 사람이 **2만원 이상** 결제했을 때만 1명이다.

| 소개 | 드리는 것 |
|---|---|
| 1명 | 오늘의 운세 30일 무료 |
| 3명 | 이번 주 행운의 번호 |
| 5명 | 월운세 6달 무료 |
| 7명 | 5만원 아래 점사 하나 무료 |
| 10명 | 신년운세 무료 |
| 15명 | 택일 **또는** 작명 중 하나 무료 |
| 20명 | 오늘의 운세·월운세·신년운세 **1년치** + 태길 1회 + 작명 1회 |

- 20명은 **평생이 아니다. 1년이다.**
- 「로또」가 아니라 **행운의 번호**다. 화면에 「로또」라는 글자를 쓰지 않는다.

## 월운세 (2026-09-26 확정)

- 값 **9,900원**
- 들어가는 것: 이번 달 전체 흐름 / 돈·일·사람 셋 / 좋은 날 셋과 조심할 날 셋 /
  이번 달에 하면 좋은 일 하나

## 행운의 번호 (2026-09-26 확정)

- 오행의 숫자(목 3·8, 화 2·7, 토 5·10, 금 4·9, 수 1·6)에서 손님에게 이로운
  기운을 골라, 그 주의 날 기운을 섞어 1~45 중 여섯 개를 뽑는다.
- **어느 기운에서 나온 번호인지 반드시 같이 적는다.**
- 「로또」·「복권」·「당첨」이라는 말을 쓰지 않는다. 사면 된다고도 하지 않는다.

## 일하는 법

- 코드는 **안티그라비티**가 짠다. 나는 지시문을 쓰고 검수한다.
- 사장님께는 **파일로 드리지 않는다.** 대화창에 통째로 적어 드린다.
- 사장님이 고칠 것을 알려주시면 **그냥 고친다.** 왜 그랬는지는 묻지 않으면 안 적는다.
- **결제 테스트는 맨 마지막에 한 번.**

# 포트원 연동 준비 — 사장님이 하실 일

> 코드는 다 되어 있다. 상점 정보 세 개만 꽂으면 결제가 돈다.
> 문제는 그 세 개를 받는 데 절차가 있다는 것이다.

---

## 한눈에

| | 사업자등록증 | 걸리는 시간 | 실제 돈 |
|---|---|---|---|
| **① 테스트 모드** | **불필요** | **오늘 5분** | 안 오감 |
| ② 실결제 | 필요 | 2~3주 | 오감 |

**①을 먼저 하십시오.** 실결제 심사가 도는 동안 우리는 이미 완성된 시스템을 테스트할 수 있다.

---

## ① 오늘 할 것 — 테스트 모드 (5분)

포트원 관리자 페이지는 **계약 없이 무료 가입**이 된다. 사업자등록증도 필요 없다.

1. https://admin.portone.io 접속 → 회원가입
2. 좌측 **결제 연동** → **테스트 연동 관리**
3. PG사 하나 선택 (아무거나. 나중에 바꿀 수 있다)
4. 저장하면 아래 세 개가 나온다:

| 값 | 어디서 | 어디에 |
|---|---|---|
| **Store ID** | 상점 정보 | `PORTONE_STORE_ID` |
| **채널 키** | 테스트 연동 관리 | `PORTONE_CHANNEL_KEY` |
| **V2 API Secret** | 결제 연동 → API Keys | `PORTONE_API_SECRET` |

5. 서버 실행:

```
PORTONE_STORE_ID=store-xxxx \
PORTONE_CHANNEL_KEY=channel-key-xxxx \
PORTONE_API_SECRET=xxxx \
ANTHROPIC_API_KEY=sk-ant-xxxx \
npm start --prefix apps/api
```

→ http://localhost:3000 에서 **테스트 카드로 결제가 끝까지 돈다.** 돈은 안 나간다.

이 단계에서 확인할 것: 결제창이 뜨는지, 결제 후 리포트가 나오는지, 취소했을 때 안내가 맞는지.

---

## ② 실결제까지 — 세 단계, 2~3주

### 1단계. 사업자등록 (하루)

**홈택스** → 사업자등록 신청. 온라인으로 되고 보통 하루면 나온다.

- 업태/종목: 정보통신업 / 응용소프트웨어 개발 및 공급업 (또는 전자상거래 소매업)
- 간이과세자로 시작해도 무방하다. 매출이 커지면 일반과세자로 전환된다.

### 2단계. PG 심사 (영업일 7~10일)

포트원 관리자 → **결제 연동** → **PG 신청**

준비물:
- 사업자등록증 사본 (업로드하면 정보가 자동으로 채워진다)
- 대표자 휴대폰번호, 생년월일
- 사업장 주소
- 정산받을 계좌

**PG 심사는 사이트를 직접 열어보고 판단한다.** 아래 요건이 안 갖춰지면 반려된다.

### 3단계. 통신판매업 신고 (1~2주)

PG 신청 후 **구매안전서비스 이용확인증**이 나오면, 그걸 들고 신고한다.

- **정부24** 또는 관할 구청 → 통신판매업 신고
- 등록면허세 약 4만 5천 원
- 신고번호가 나오면 사이트 하단에 표기

순서 주의: **PG 신청 → 구매안전서비스 확인증 → 통신판매업 신고** 순이다.
PG 신청할 때는 통신판매업 신고번호를 안 적어도 된다.

---

## PG 심사를 통과하려면 사이트에 있어야 하는 것

여기가 **우리가 코드로 만들어야 할 부분**이다. 지금은 없다.

### 필수 — 없으면 반려된다

- [ ] **사업자정보 표시** (모든 페이지 하단)
  - 상호, 대표자 성명, 사업장 주소, 전화번호, 이메일
  - 사업자등록번호, 통신판매업 신고번호
  - 개인정보관리책임자
  - ⚠️ **PG에 제출한 사업자정보와 글자 하나까지 같아야 한다**
- [ ] **이용약관** 페이지
- [ ] **개인정보처리방침** 페이지
- [ ] **환불·취소 정책** — 상품 페이지에서 바로 보여야 한다
  - 우리는 이미 결제 화면에 청약철회 고지가 있다. 별도 페이지도 필요하다.
- [ ] **고객센터 연락처** — 실제로 닿는 번호나 이메일
- [ ] **상품 가격과 내용이 명확히 표시**된 페이지

### 이미 되어 있는 것

- ✅ 청약철회 제한 고지 (결제 화면)
- ✅ 미리보기 제공 (시험 사용 요건)
- ✅ 환불 처리 기한 안내 (3영업일)
- ✅ 상품명·가격 표시

## 지금 정해야 할 것

PG 심사에 필요해서, 코드보다 먼저 정해야 하는 값들이다.

| 항목 | 왜 필요한가 | 정하셨나 |
|---|---|---|
| 서비스 이름 | 상호·도메인·약관에 전부 들어간다 | ☐ |
| 도메인 | PG가 그 주소를 직접 열어본다 | ☐ |
| 고객센터 이메일 | 필수 표기 항목 | ☐ |
| 고객센터 전화 | 필수 표기 항목 (휴대폰도 가능) | ☐ |
| 사업장 주소 | 자택도 가능 | ☐ |

이게 정해져야 약관·개인정보처리방침·푸터를 만들 수 있다.

## 권장 순서

```
오늘        ① 포트원 가입 → 테스트 모드 → 결제 흐름 확인
그 다음     사업자등록 신청 (하루)
동시에      약관·개인정보처리방침·푸터 페이지 제작 (코드)
            ↓
            PG 신청 (심사 7~10일)
            ↓
            구매안전서비스 확인증 → 통신판매업 신고
            ↓
            실결제 개시
```

**심사가 도는 2주 동안 놀지 않는다.** 그 사이 배포·DB·신년 패키지를 만들면 된다.

신년운세 시즌이 11월 오픈 마감선이므로, 역산하면 **9월 중에는 PG 신청이 들어가야** 안전하다.

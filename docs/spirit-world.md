# 신령계 — 사장님이 정한 컨셉 (2026-09-03)

사장님이 말씀하신 것을 그대로 적는다. 여기가 앞으로의 기준이다.

## 한 줄

**우리 사이트는 홈페이지가 아니라 신령계다.**

## 손님이 겪는 순서

1. **바람신령이 데려온다.** 인스타·메타 광고에서 손님을 인도해 온다.
   바람신령은 이동(역마)을 맡은 신령이라 이 역할이 맞다.

2. **문 앞에서 이름을 밝힌다.** 이름·생년월일·태어난 시를 밝혀야 문이 열린다.
   개인정보를 받는 창이 아니라 **입장 의식**이다. 같은 것을 받더라도
   「정보를 입력하세요」와 「이름을 밝히시오」는 다른 화면이다.

3. **신령계가 펼쳐진다.** 꽃 있는 데 꽃신령, 실 걸린 나무에 실신령,
   달 비친 연못에 달신령. 띄엄띄엄 서 있다.

4. **신령을 누르면** 그 신령이 봐 주는 것들이 나온다.
   - 꽃신령 → 매력 삼합 · 솔로 탈출 · 결혼 시기
   - 실신령 → 궁합 리포트 · 썸 궁합
   - 달신령 → 재회 가능성
   - 산신령 → 우리 아이 · 자녀 진로 · 부모자식 궁합 · 노후
   - 거울신령 → 사주 종합 · 삼합 · 재능운 · 사람운 · 귀인운
   - 곳간신령 → 돈그릇 · 출세운 · 공부운
   - 바람신령 → 오늘 운세 · 신년운세 · 이동운

5. **앞은 보여 주고 뒤는 가린다.** 문에서 이미 생년월일을 받았으므로
   사주는 나와 있다. 앞부분은 쉬운 말로 풀어 주고, **정작 중요한 뒷부분은
   가려 둔다.** 궁금하면 그 자리에서 결제한다.

## 더 할 것

- **재회가 하나뿐이라 심심하다.** 달신형 칸에 상품 하나 더. (심사 통과 뒤)
- **골라 보기.** 「관상+손금만」 「사주+손금만」 「사주만」 같은 조합.

## 조심할 것

**문으로 막으면 카드사 심사가 안을 못 본다.** 심사는 상품과 가격을 봐야 하는데
문 앞에서 막힌다.

그래서 `/products` 를 **문 밖에** 둔다. 손님은 신령계로 들어가고,
심사는 가격표 주소로 바로 간다. 지금 이미 그렇게 되어 있다.

## 그림

**디자인은 사장님이 뽑으신다.** 코드 쪽은 프롬프트만 적어 두고, 뽑힌 그림을
받아서 붙인다.

## 만드는 순서

- [ ] 1. 문 — 이름·생년월일·태어난 시를 받는 입장 화면
- [ ] 2. 신령계 — 배경 위에 신령이 서 있고, 누르면 상품이 펼쳐진다
- [ ] 3. 가리기 — 풀이 앞부분만 보여 주고 뒷부분은 가린 뒤 결제로 잇는다
- [ ] 4. 조합 상품 — 관상+손금만, 사주+손금만, 사주만
- [ ] 5. 재회 상품 하나 더

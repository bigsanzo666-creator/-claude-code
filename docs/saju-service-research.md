# 사주 + 관상 + 손금 통합 서비스 — 사전조사 및 방향성

작성: 2026-08 / 목적: 서비스 컨셉 확정 전 시장·경쟁·규제 사전조사

---

## 0. 결론 먼저

1. **시장은 크고 아직 안 끝났다.** 국내 점술 시장 약 1조 4,000억 원. 상위 플레이어가 이미 있지만 "AI 해석 성능이 상향평준화"되면서 경쟁축이 *해석 정확도 → 콘텐츠 형태*로 이동 중이다. 지금이 진입 타이밍이다.
2. **우리의 차별점은 "3종 병렬 제공"이 아니라 "3종 교차검증"이어야 한다.** 사주·관상·손금을 각각 따로 보여주는 건 이미 여러 곳이 한다. **세 결과가 일치하는 항목 / 엇갈리는 항목을 명시적으로 대조**해주는 서비스는 아직 없다. 이게 유일한 방어선.
3. **가장 큰 기술 리스크는 AI가 아니라 만세력이다.** LLM에 사주팔자를 계산시키는 순간 서비스가 망한다. 명식은 결정론 엔진, 해석만 LLM.
4. **가장 큰 법적 리스크는 얼굴/손 사진이다.** 생체정보다. → **온디바이스 특징점 추출 후 원본 미전송**이 정답이자 동시에 마케팅 포인트.
5. **초기엔 상담사 중개(1:1 전화상담)를 하지 마라.** 매출은 크지만 인력·정산·CS 비용이 1인/소규모 팀을 죽인다.

### 1.3 AI 전환은 이미 끝난 전제
- 상위 10개 운세 앱 중 **6개가 AI 기능 탑재**. 점신·포스텔러·헬로우봇·우주고양이 보라·오즈의 타로 5개 앱 MAU 합계 124만.
- 2026년 1월 조사: **AI로 운세를 본다 40.7%** vs 유명 점집 직접 방문 18.5%.
- 즉 "AI로 사주 본다"는 더 이상 차별점이 아니다. **AI는 기본기, 차별점은 형식과 신뢰**다.

### 1.4 사용자 특성
- 주 사용층 **20~30대 여성**
- 결과 **SNS 공유율 약 35%** → 공유 설계가 곧 획득 채널
- 소비 동기: 예측보다 **자기 이해 + 위로("힐링 문화")**

## 2. 잘 되는 패턴 (검증된 것)

1. **무료는 넓게, 유료는 깊게.** 포스텔러는 유료화 비율이 **5%뿐인데도** 최상위권. 무료 폭이 넓을수록 결제층의 절대수가 커진다.
2. **소액 단계 결제.** 큰 구독 하나가 아니라 코인 충전 → 리포트별 언락. 진입장벽이 낮아 첫 결제가 쉽다.
3. **재구매율이 진짜 지표.** 12개월 재구매율 65~77%가 상위권 기준선. 신규 획득보다 재방문 훅 설계가 우선.
4. **시즌성 설계.** 신년운세·토정비결이 연말연시에 폭발. 금융사·웹툰 플랫폼이 무료 운세를 뿌리는 이유도 이 시기 앱 락인 효과 때문.
5. **공유 가능한 결과물.** 카드·그래프·캐릭터·웹툰 형태. 텍스트 벽은 공유되지 않는다.
6. **시각적 차별화가 지금의 경쟁축.** 타이트사주의 100배 성장은 해석이 아니라 **웹툰 포맷** 때문이었다.
7. **신뢰 장치.** 후기·별점·전문가 감수 표기. 점신의 "배달앱식 상담사 선택 UI"가 대표적.

## 3. 아쉬운 점 = 우리의 기회

실사용자 리뷰와 비교 분석에서 반복적으로 나오는 불만:

| 문제 | 구체적 증상 | 우리가 잡을 지점 |
|---|---|---|
| **뻔한 내용** | "오늘 운세나 토정비결 보면 다 좋다고만 나온다", "제일 안 맞는다" | 좋은 말 나열 금지. 강점/약점/주의시기를 **명확히 대조**해서 제시 |
| **즉시 과금** | 결과 첫 화면이 결제벽 → 별점 폭락 | 무료 구간에서 이미 "값어치 있다"는 경험을 끝내기 |
| **명식 불일치** | 앱마다 사주팔자 8글자가 다르게 나옴 (절입시각·진태양시·야자시 처리 상이) | **계산 근거를 공개**하고 옵션을 사용자에게 노출 |
| **AI 계산 오류** | LLM이 생년월일→간지 변환을 "패턴 추측"으로 처리 → 한 글자만 틀려도 전체 해석 왜곡 | 결정론 엔진으로 계산, LLM은 문장화만 |
| **일관성 없음** | 질문 방식에 따라 정반대 답. 유도 질문에 동조 | 같은 명식+같은 질문 = 같은 답 (캐싱 + 저온도 + 룰 고정) |
| **재방문 이유 없음** | 한 번 보고 이탈 | 일진 기반 매일 변하는 콘텐츠 + 알림 |
| **관상/손금은 껍데기** | 사진 올리면 근거 없는 문장만 출력 | 추출한 **특징(landmark)을 화면에 표시**하고 그 특징 → 해석의 연결을 보여주기 |

## 4. 서비스 컨셉 정의

### 한 줄
> **선천(사주) · 기질(관상) · 변화(손금)를 하나의 리포트에서 교차검증하는 종합 리딩 서비스**

### 왜 이게 방어선인가
- 사주만: 이미 포화. 포스텔러/점신과 정면충돌.
- 관상만/손금만: 콘텐츠 깊이가 부족해 재구매가 안 붙음.
- **셋을 교차**: 
  - "사주는 재물운 강, 관상도 동일 → **강한 확신 항목**"
  - "사주는 대인관계 원만, 손금은 단절 → **주의 항목, 이 부분은 노력 변수**"
  - 이 **일치/불일치 매트릭스** 자체가 남들이 못 만드는 결과물이자, 그대로 공유 카드가 된다.
- 부가 효과: 사진을 올릴 이유가 생기므로 **온보딩 완주율과 체류시간**이 올라간다.

### 톤앤매너 원칙
- 단정("~한다") 금지 → 경향("~한 편이다")
- 불안 조장 금지. 공포 마케팅은 단기 매출·장기 자살행위.
- 결과는 **행동 제안으로 끝난다**(마이파이의 "해석에서 실행까지" 구조가 좋은 참고).

## 5. 해야 할 것 (DO)

### 5.1 기술
- [ ] **만세력 자체 엔진 + DB 구축.** 24절기 절입시각을 **분 단위**로, 진태양시 경도 보정(서울 기준 약 −32분), 서머타임 구간(1948~1988 사이 시행 연도) 반영, **야자시/조자시 처리를 사용자 선택 옵션**으로 제공하고 기본값을 명시.
- [ ] **계산과 해석의 완전 분리.** `birth → (결정론 엔진) → 명식 JSON → (룰 엔진: 십신·용신·십이운성·신살) → 구조화 결과 → (LLM: 문장화만)`
- [ ] **결과 캐싱 + 저온도.** 같은 입력 = 같은 출력. 일관성이 신뢰의 90%.
- [ ] **관상/손금은 온디바이스 특징 추출.** MediaPipe FaceLandmarker / HandLandmarker로 브라우저에서 랜드마크만 뽑고, **서버에는 좌표·특징 태그만 전송, 원본 이미지는 업로드하지 않는다.** 법적 리스크가 통째로 사라지고 "사진이 서버로 가지 않습니다"가 그대로 카피가 된다.
- [ ] **웹 우선(PWA).** 앱스토어 수수료 30% 회피 + 배포 속도 + SEO. 앱은 검증 후.
- [ ] **결과 OG 이미지 자동 생성** (공유율 35% 시장이다).

### 5.2 콘텐츠·UX
- [ ] 무료: 명식표, 오행 밸런스 그래프, 오늘의 일진, 관상 1차 요약 / 유료: 심층 리포트·교차검증 매트릭스·연간 흐름
- [ ] 매일 바뀌는 훅: 내 일주 대비 오늘의 일진 → 푸시/카톡 알림
- [ ] 결과 문서는 **카드 단위**로 쪼개기 (스크롤 텍스트 벽 금지)
- [ ] 신뢰 표기: 계산 기준·해석 근거·감수자

### 5.3 수익화
- [ ] **3층 구조**: 코인 소액 결제(1,000~3,000원 단품) / 종합 리포트 패키지(15,000~30,000원) / 연간 구독
- [ ] **궁합·커플 리딩**: 2인 입력 → ARPU 자연 2배. 공유 유발도 최고.
- [ ] **신년 시즌 패키지가 캐시카우.** 11월 오픈이 데드라인 → 역산하면 **9~10월에 사주 리포트가 완성**돼 있어야 한다.
- [ ] 초기 광고 미도입(포스텔러 무광고 전략). 광고 수익보다 결제 전환 훼손이 크다.

### 5.4 법무·리스크
- [ ] **생체정보**: 얼굴·손 이미지는 「생체정보 보호 가이드라인」(2021.9) 대상. 생체인식 특징정보는 민감정보 → **별도 동의 분리 필수**, 암호화 저장 의무. → 온디바이스 처리 + 미저장으로 회피하는 게 최선.
- [ ] **전자상거래법**: 디지털콘텐츠는 제공 개시 시 청약철회가 제한되지만, **"철회 불가 사실의 표시 + 시험 사용(미리보기) 제공"을 하지 않으면 그 제한을 주장할 수 없다.** → 결제 전 고지 문구 + 리포트 샘플/미리보기 필수. 환불은 철회일로부터 **3영업일** 내.
- [ ] 통신판매업 신고, 이용약관에 "오락 및 자기이해 목적. 의료·법률·투자·진로에 대한 전문적 조언이 아님" 명시
- [ ] 미성년자 결제 취소 대응 프로세스
- [ ] 질병·수명·사망·임신 여부 예측 문구 전면 금지

## 6. 하지 말아야 할 것 (DON'T)

1. **LLM에게 만세력을 계산시키지 마라.** 가장 흔하고 가장 치명적인 실패. "GPT 래핑" 서비스가 리뷰에서 죽는 이유가 이것이다.
2. **초기에 1:1 상담사 중개를 붙이지 마라.** 상담사 모집·검증·정산·노쇼·환불 CS가 개발 리소스를 전부 잡아먹는다. 콘텐츠형으로 트래픽을 만든 뒤 붙여도 늦지 않다.
3. **앱부터 만들지 마라.** 30% 수수료 + 심사 + SEO 부재. 웹 → PWA → 앱 순서.
4. **얼굴에 점수를 매기지 마라.** "외모 78점" 류는 알고리즘 편향(피부색에 따른 점수 차이 연구 사례 존재) + 청소년 정신건강 이슈로 논란 직행. **점수 대신 "유형·기질" 언어**를 쓴다.
5. **부적·개운상품·굿 알선 금지.** 규제·평판·PG 심사 리스크가 매출보다 크다.
6. **결과 첫 화면 결제벽 금지.**
7. **원본 사진 서버 장기 보관 금지.**
8. **공포 마케팅 금지.** ("올해 큰 사고가 있습니다" 류)
9. **타 서비스 풀이 텍스트 크롤링·복제 금지.** 저작권 + 우리 차별점 상실.
10. **매번 답이 달라지게 두지 마라.** 온도 높은 LLM = 신뢰 붕괴.

## 8. 성공 지표 (기준선은 업계 실측치)

| 지표 | 목표 | 근거 |
|---|---|---|
| 무료→유료 전환율 | 3~5% | 포스텔러 5% |
| 12개월 재구매율 | 60%+ | 상위권 65.6~77.4% |
| 결과 공유율 | 30%+ | 시장 평균 약 35% |
| 명식 정확도 | 타 서비스 3곳 교차검증 100건 일치율 100% (불일치 시 사유 설명 가능) | 앱별 명식 불일치가 실제 불만 요인 |
| 리포트 재열람률 | 40%+ | "한 번 보고 끝" 문제의 반증 지표 |

## 9. 기술 스택 제안

- **프론트**: Next.js (App Router) + PWA, 결과 카드 OG 이미지 동적 생성
- **명식 엔진**: TypeScript 또는 Python 별도 모듈. 절기 데이터는 자체 DB 테이블(외부 API 의존 금지 — 서비스 정확도가 남의 가용성에 묶인다)
- **해석**: 룰 엔진(결정론) → LLM 문장화. 프롬프트 캐싱으로 비용 절감
- **이미지**: MediaPipe FaceLandmarker / HandLandmarker — **브라우저 내 실행**
- **DB**: Postgres (명식·리포트·결제 이력)
- **결제**: 포트원 또는 토스페이먼츠 (웹 결제)
- **비용 통제**: 리포트당 LLM 원가를 판매가의 10% 이하로 유지 → 무료 구간은 LLM 미사용(룰 기반 템플릿)으로 처리

## 10. 수익 경계선 (확정)

무료와 유료를 **기능**이 아니라 **단독이냐 합본이냐**로 가른다.

| 구간 | 내용 | 원가 |
|---|---|---|
| **무료** | 사주 단독 (명식·해석·대운·세운·일진), 관상 단독, 손금 단독, 궁합 | **0원** — 전부 룰 엔진, 브라우저 내 계산 |
| **유료** | 사주 × 관상 × 손금 **교차검증**, AI 서술형 리포트 | LLM 호출분만 |

이 선을 고른 이유:
- 남들도 하는 것(단독 풀이)은 무료로 주고, **우리만 할 수 있는 것(교차검증)을 판다.**
- 무료 구간에 LLM이 없어 트래픽이 늘어도 원가가 0에 수렴한다. "무료 폭을 넓게"라는 전략을 실제로 감당할 수 있다.
- 유료가 "따로 본 걸 붙여놓은 것"으로 보이면 안 된다. 그래서 세 갈래를 **공통 8축**으로 환산해,
  합쳤을 때만 나오는 정보(일치·엇갈림)를 만든다.

**설계 요건:** 유료 구간의 가치는 전적으로 "엇갈림" 항목에 달렸다.
전부 일치하면 살 이유가 없고, 전부 엇갈리면 신뢰를 잃는다.

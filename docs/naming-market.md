# 작명·택일 시장 — 조사와 결론

조사일 2026-09-05. 그록으로 뒤진 것을 추린다. 출처는 원문에 URL이 붙어 있다.

## 결론부터 — **택일을 먼저 한다**

작명은 이미 꽉 찼고 택일은 비어 있다. 그리고 순서가 그쪽이 맞다 —
날을 잡는 것이 먼저고 이름은 그 다음이다. 택일을 산 사람은 이름도 사지만,
이미 태어난 사람에게는 택일을 팔 수 없다.

## 지금 시장

| | 값 | 방식 |
|---|---|---|
| 작명 · 앱 | 몇천원 ~ 3만 | 자동 |
| 작명 · 웹 | 7.8만 ~ 10만 | 반자동 |
| 작명 · 사람 | 10만 ~ 30만 | 전화·방문 |
| **택일** | **10만 ~ 25만** | **거의 전부 전화·방문** |

**웹에서 결제하고 바로 길일이 나오는 곳을 못 찾았다.** 앱 하나(모두맘)가
기능으로 갖고 있을 뿐이고, 나머지는 전부 상담이다.

## 우리가 파고들 자리 넷

1. **병원 일정에 맞춘다.** 역술가는 날짜 셋을 주고 끝낸다. 병원 스케줄과 안
   맞으면 그냥 못 쓴다(나무위키 택일 항목에 그대로 적혀 있다). 우리는 손님이
   의사한테 받은 후보 날짜와 수술 가능 시간대를 넣으면 **그 안에서만** 점수를
   매긴다. 전화 상담은 이걸 못 한다.
2. **인명용 한자를 최신으로 쓴다.** 2024-06-11에 1,070자가 늘어 9,389자가
   됐는데, 지음 앱은 아직 「8,100자(2015년 기준)」라고 써 놓았다. 낡은 표는
   쓸 수 있는 글자를 못 쓴다고 하는 셈이다.
3. **못 지키면 다시 뽑아 준다.** 「택일했는데 진통이 먼저 와서 못 지켰다,
   환불도 없다」가 반복되는 불만이다. 우리는 자동이라 다시 뽑는 데 돈이 안 든다.
   그것을 정책으로 박는다.
4. **유파를 밝힌다.** 어느 집도 무슨 유파로 셈하는지 안 적는다. 발음오행만 해도
   ㅇ·ㅎ을 水로 보는 데와 土로 보는 데가 갈린다. 우리는 종이에 적는다.

빈 가격대는 **3만~7만**이다. 앱과 숨고에만 있고 제대로 된 웹이 없다.

## 수요

| | 수 |
|---|---|
| 출생아 (2025 잠정) | 25만 4,500 |
| 제왕절개 비율 (2024) | 66.9% (건보 다른 집계는 67.4%) |
| → 제왕절개 건수 | **연 약 16만** |
| 개명 (2025) | 7.7만, 해마다 줄고 있다 |

**모르는 것 하나.** 제왕절개 16만 중 택일을 하는 비율. 5%면 8천 명이고 30%면
5만 명이라 완전히 다른 장사다. 네이버 데이터랩에서 「제왕절개 택일」·「출산
택일」 검색량 추이부터 봐야 한다. 공짜고 5분이면 된다.

## 법

- 작명업 인허가 조항은 못 찾았다. 통신판매 신고는 우리가 이미 한다.
- 인명용 한자 — 가족관계등록법 제44조③, 규칙 제37조. **9,389자**.
  규칙은 2025-06-26 개정, 2025-07-19 시행.
- 범위 밖 한자면 등록부에 한글만 올라간다. 그래서 **거르지 않으면 손님이
  출생신고를 못 한다.** 이 표는 필수다.
- 헌재 2015헌마964 — 인명용 한자 제한은 작명 자유 침해가 아니다.
- 표시광고법 제3조. 판 적 없는 정가로 할인율을 부풀리지 않는다(우리는 이미
  묶음가에서 같은 원칙을 지키고 있다).

## 만들 것

1. **택일** — 후보 날짜와 가능한 시간대를 받아 점수를 매겨 순위를 낸다.
   점수는 중화·오행 고름·빈 오행·충·귀인 다섯 가지로만 낸다. 전부 계산에서
   나오는 값이다. (2026-09-05에 손으로 돌려 보니 잘 나왔다 — 2027년 한 해
   3,650칸을 훑어 최고 81점, 한가운데 46점이었다. 점수는 절대값이 아니라
   같은 기간 안에서 비교하는 눈금이다.)
2. **인명용 한자 9,389자 표** + 획수표(원획법) + 81수 길흉표
3. **작명** — 사주에서 필요한 오행을 잡고, 성과 끝자의 획수에 맞춰 가운데
   글자의 획수 후보를 내고, 인명용 안에서 고른다
4. 신령 하나를 더 세운다 — 날을 잡아 주는 신령

# 상품 전략 — 늘봄사주

> 경쟁사 분석, 상품 구성, 작명, 화면 원칙을 한 곳에 모은 문서.
> 12개 서비스를 다 보고 나면 여기에 이어 붙인다.

## 0. 한 줄 결론

**엔진은 이미 다 계산하고 있다. 잘라서 이름 붙이고 값을 매기는 일이 남았다.**

지금 파는 것 3개, 같은 재료로 만들 수 있는 것 12개 이상.
새로 만들 계산은 없다.

## 1. 경쟁사 분석

### 타이트사주 (sajutight.me)

시장 1위. 2024년 월 1천만원 → 작년 **월 10억원**. 개발사 사이버네틱스.
사주풀이를 웹툰·만화로 그려주는 것이 성장 동력.

#### 결과 화면 구조 (위 → 아래)

| 위치 | 무엇 | 노림수 |
|---|---|---|
| 최상단 | **`84점`** 큰 숫자 하나 | 3초 안에 결과를 준다. 스크롤 이유를 만듦 |
| ② | 색깔 막대 5~6개 | 숫자를 눈으로. 캡처·공유하기 좋음 |
| ③ | 동그란 아이콘 12개 그리드 | 명리 개념을 그림으로. 글자 공포 제거 |
| ④ | 긴 본문 (무료) | 여기까진 넉넉히 준다 |
| ⑤ | **블러 처리된 문단들** | 핵심 장치 (아래) |
| ⑥ **페이지 중간** | 자물쇠 달린 결제 버튼 | 맨 아래가 아니라 중간 |
| ⑦ | 파스텔 카드 (분홍·파랑·초록) | 구간마다 색을 바꿔 지루함 차단 |
| ⑧ 하단 | 웹툰 썸네일 콘텐츠 카드 | 이탈 직전 회유 |
| ⑨ 최하단 | 결제 버튼 한 번 더 | 끝까지 읽은 사람 회수 |

#### 배울 장치 3개

**① 블러 — "안 보여주기"가 아니라 "보여주고 못 읽게 하기"**

글이 빽빽하게 있는 게 보이는데 흐려서 못 읽는다. **분량이 눈에 보인다.**
"10페이지 분량"이라고 글로 쓰는 것보다 훨씬 세다.
우리는 현재 텍스트 일부만 잘라서 보여준다 — 분량이 느껴지지 않는다.

**② 결제 버튼이 페이지 한가운데**

막 재미있어지려는 순간에 막는다. 끝까지 읽고 나면 이미 만족해서 안 산다.

**③ 84점**

사주에 원래 점수 같은 건 없다. 만들어낸 것이다.
하지만 이게 있어서 캡처해 친구에게 보낸다.

> **우리의 차이**: 우리 8축 점수는 룰 엔진에서 나온 값이라 **근거를 댈 수 있다.**
> 저쪽은 84점이 어디서 나왔는지 밝히지 않는다. 이게 우리 무기이므로 버리지 않는다.

#### 결제 팝업의 장치 5개

실제 문구: 「매력살 분석 리포트 / 도화살 홍염살 화개살 심층 분석」

| 장치 | 저쪽 | 우리는 |
|---|---|---|
| 구체적 예고 | 도화살·홍염살·화개살 셋을 못 박음 | ✅ 따라한다. "일치/엇갈림/단독" 셋으로 |
| 권위 | 더현대(현대백화점) 팝업 협업 | ❌ 없다. 만들지 않는다 |
| 사회적 증거 | 누적 고객 30,000명 | ❌ 0명이다. 거짓말하지 않는다 |
| 분량 명시 | 심층 리포트 15,000자+ | ✅ **실측값**을 쓴다 (현재 4,000~6,000자) |
| 가격 앵커 | ~~36,740원~~ → 46% **19,900원** | ✅ 단, **진짜 근거**로 (아래) |

버튼 문구가 `결제하기`가 아니라 **`결과 보러가기`** — 돈 내는 행위를 감췄다.

#### 가격

**타이트사주 = 19,900원. 우리와 동일.**

> 초기에 "우리 가격이 시장가의 3~20배"라고 판단했으나 **틀렸다.**
> 990원대는 항목을 하나씩 파는 저가 모델이고, 종합 리포트 한 방을 파는
> 모델의 시장가는 19,900원이다. **가격은 건드리지 않는다.**
> 문제는 가격이 아니라 "19,900원어치로 보이지 않는 화면"이었다.

#### 가격 앵커를 정직하게 만드는 법

저쪽의 `36,740원`은 실제로 판 적 없는 값일 가능성이 높다 —
표시광고법상 거짓·과장광고 소지가 있다. 우리는 그럴 필요가 없다.

```
사주 종합 리포트      9,900원   ← 실제로 파는 상품
궁합 리포트          14,900원   ← 실제로 파는 상품
                    ─────────
따로 사면            24,800원
삼합 리포트 묶음      19,900원   (20% 절약)
```

카탈로그에 저 두 상품이 실재하므로 이 할인은 사실이다.

#### 버튼 문구 — 다크패턴 주의

`결과 보러가기`처럼 결제임을 감추면 다크패턴이고,
우리가 이미 넣어둔 청약철회 고지·동의 체크와도 어긋난다.

**금액을 버튼에 넣어 해결한다**: `전체 결과 보기 · 19,900원`

## 2. 상품 지도

### 핵심 구조

경쟁사는 상품을 각각 따로 만들지 않는다. 하나의 명식에서 나온 해석을
**주제별로 잘라서** 각각 상품화한다. 계산은 한 번, 파는 건 열 번.

```
생년월일시 → 명식 8글자 → 해석
                            ├── 재물운
                            ├── 출세운
                            ├── 결혼운
                            ├── 자녀운
                            └── ...
```

### 우리 엔진이 이미 계산 중인 것

| 팔 수 있는 상품 | 이미 있는 코드 |
|---|---|
| 매력살 | `findSinsal()` — 도화살·홍염살 |
| 재물운 | 십신의 **재성**(정재·편재) |
| 출세운 | 십신의 **관성**(정관·편관) |
| 자녀운 · 재능운 | 십신의 **식상**(식신·상관) |
| 시험운 · 문서운 | 십신의 **인성**(정인·편인) |
| 신년운세 | `annualLuck()` |
| 오늘의 운세 | `dailyLuck()` |
| 10년 흐름 | `calculateDaeun()` |
| 궁합 | `compatibility()` — 5축 |
| 이동·해외운 | `TRAVELING_HORSE` |
| 귀인운 | `CHEONEUL` |
| 삼합 리포트 | `crossValidate()` — **국내 유일** |

### 콘텐츠가 많아야 하는 이유 3가지

1. **검색 입구가 늘어난다.** 사람들은 `사주`로 검색하지 않는다.
   `재물운 사주`, `결혼 시기 사주`, `도화살 뜻`으로 검색한다.
2. **재구매가 생긴다.** 재물운 산 사람이 다음 달 결혼운을 산다.
   새 손님을 데려오지 않아도 매출이 는다.
3. **가격 사다리가 생긴다.** 현재 첫 결제가 9,900원 — 처음 온 사람에겐 높다.
   첫 결제의 심리적 장벽이 가장 높으므로, 싼 것으로 한 번 넘게 만든다.

### 목표 가격대

```
 3,900원   오늘의 운세 · 매력 삼합        ← 첫 결제 장벽 낮추기
 9,900원   돈그릇 · 출세운 · 결혼운 · 자녀운 · 시험운 ...  ← 주력, 재구매
14,900원   궁합 · 신년운세
19,900원   삼합 리포트 (사주×관상×손금)    ← 우리만 되는 것
```

## 3. 작명

### 공식

```
도화살 · 홍염살 · 화개살   →   "매력살 분석 리포트"
   (아무도 모르는 말)          (누구나 아는 말 + 명리 냄새)
```

쉬운 말로 후킹하고 명리 용어로 격을 세운다. 둘 중 하나만 있으면 실패한다.
- 「도화살 리포트」 → 뭔지 모른다
- 「매력 분석」 → 흔해빠졌다

### 후보 (미확정 — 사장님 결정 대기)

| 우리 계산 | 후보 1 | 후보 2 | 비고 |
|---|---|---|---|
| 관성 | **출세운** | 자리운 | 「커리어운」은 영어라 붕 뜬다 — 기각 |
| 재성 | **돈그릇** | 재물운 | 「돈그릇」이 요즘 말이고 검색도 된다 |
| 식상 | 자녀운 | 끼운(재능운) | **둘 다 따로 판다** — 같은 계산, 상품 2개 |
| 인성 | 시험·합격운 | 문서운 | **둘 다** — 문서운에 부동산 계약 포함 |
| 신살 | **매력 삼합** | 매력살 | 아래 참고 |
| 세운 | **신년운세** | 올해의 운 | 11월 대목 |
| 일진 | **오늘의 운세** | — | 3,900원 미끼상품 |
| 대운 | **10년 흐름표** | 인생 그래프 | |
| 역마살 | **이동·해외운** | 역마 리포트 | |
| 천을귀인 | **귀인운** | — | "누가 나를 돕는가" |

### 三合 — 간판 상품 이름

**三合**은 명리 용어(지지 삼합)이면서 글자 그대로 **"셋이 합친다"**이다.

> **사주 · 관상 · 손금 — 삼합 리포트**

- 명리 용어라 격이 있고
- 뜻이 그대로 서비스 설명이고
- **아무도 못 쓴다** — 셋을 다 보는 곳이 우리뿐이므로

「매력 삼합」도 같은 줄기. 타이트사주의 「매력살」을 베끼는 것이 아니라
**매력을 사주·관상·손금 셋으로 본다**는 우리 물건이 된다.

## 4. 화면 원칙 — 용어 병기

**이것이 우리의 진짜 차별점이 될 수 있다.**

경쟁사들은 명리 용어를 그냥 던진다. 손님은 이렇게 된다.

> "식상? 식상이 뭔데?"
> "인성? 사람 인성 말하는 건가?"
> 그런데 화면엔 갑자기 「자녀운」, 「시험 합격운」이 나온다.

**용어와 결과 사이가 비어 있다.** 손님은 왜 그런 결론이 나왔는지 모른 채
결과만 받는다. 그래서 다음에 또 와야 할 이유도 생기지 않는다.

### 우리 방식

```
돈그릇  ·  재성(財星)
        └ 내가 다루는 재물과 사람을 뜻합니다

당신의 명식에는 재성이 하나도 없습니다. 이건 돈을 못 번다는 뜻이 아니라 …
```

- **큰 글씨는 쉬운 말** (돈그릇)
- **옆에 작은 글씨로 명리 용어** (재성 財星)
- **한 줄로 그 용어의 뜻**
- 그 다음에 결과

이건 새로 만드는 원칙이 아니다. 우리 리포트 규칙에 이미
**"모든 결론에 근거를 단다"**가 들어 있다. 그것을 화면까지 밀고 나가는 것이다.

### 왜 이게 팔리는가

- 손님이 **배운다.** 배우면 다시 온다.
- 「식상이 뭐야?」로 검색해서 들어온 사람이 우리 페이지에서 답을 얻는다 — 검색 유입
- 겁주기 없이 신뢰를 만든다. 근거를 보여주는 쪽이 결국 이긴다

## 5. 이번 주 목표 (사장님 지시)

**"이번 주 안에 결제를 받을 수 있게 만든다."**

### 정직하게 짚어둘 것

포트원 PG 심사에 **7~10 영업일**이 걸리고, 아직 제출 전이다.
따라서 **이번 주 안에 실제 카드 승인이 나는 것은 물리적으로 불가능하다.**

대신 이렇게 정의한다.

> **이번 주 안에 "스위치만 켜면 되는 상태"를 100% 완성한다.**
> 심사가 끝나는 날 환경변수 4개를 채우면 그 즉시 결제가 열린다.

포트원 **테스트 모드는 사업자 심사 없이 지금 바로 쓸 수 있으므로**,
결제 흐름 전체를 실제로 돌려보는 것까지 이번 주에 끝낸다.

### 할 일

| # | 할 일 | 비고 |
|---|---|---|
| 1 | **포트원 서비스 URL 제출** | 가장 먼저. 심사 시계를 지금 돌린다 |
| 2 | 상품 카탈로그 3개 → 12개 | 엔진 변경 없음. 잘라서 이름 붙이기 |
| 3 | 화면 전면 개편 | 브랜드·용어 병기·블러 미리보기·중간 결제 버튼 |
| 4 | 주문 저장소 Postgres 교체 | **결제 켜기 전 필수.** 지금은 재시작하면 주문이 날아간다 |
| 5 | 포트원 테스트 모드로 전 과정 검증 | 실제 돈 0원 |

## 6. 미결정

- 상품 이름 최종 확정 (위 후보 중 선택)
- 주 고객층 — 유튜브 늘봄이야기 시청자(시니어) 유입 여부에 따라
  글씨 크기·배경 밝기가 달라진다
- 12개 경쟁사 조사 결과 반영 (사장님 진행 중)
- 리포트 분량을 늘릴지 (현재 4,000~6,000자, 타이트사주 15,000자+ 표기)

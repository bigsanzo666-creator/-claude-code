# 배포 — neulbomsaju.co.kr

> 목표는 하나다. **포트원 심사자가 주소를 열었을 때 사이트가 떠 있는 것.**
> 결제가 돌아갈 필요는 없다. 심사가 보는 건 사이트의 존재와 정책 페이지다.

## 왜 결제 없이 먼저 띄우는가

순서가 이렇게 얽혀 있다.

```
사이트가 떠 있어야  →  PG 심사를 통과하고
PG 심사를 통과해야  →  결제 기능을 켤 수 있다
```

그래서 결제를 켜고 나서 배포하려 하면 영원히 못 띄운다.
**심사 대기 모드**(`apps/api/src/standby.ts`)가 이 매듭을 푼다 —
포트원 설정이 없으면 결제 버튼을 감춘 채로 뜨고, 무료 풀이와 정책 페이지는 그대로 돈다.

꺼진 결제를 조용히 성공시키지 않고 402로 거부하는 이유는, 설정 누락이
"결제는 됐는데 리포트가 안 나온다"로 나타나면 그때는 이미 돈이 오간 뒤이기 때문이다.

## 무엇을 쓰는가

| | 선택 | 이유 |
|---|---|---|
| 도메인 | 가비아 `neulbomsaju.co.kr` | 구매 완료 |
| 서버 | 렌더(Render) 싱가포르 | 웹 화면만으로 끝난다. 명령어 안 씀. 한국에서 가장 가까운 지역 |
| 이미지 | `Dockerfile` | 플랫폼에 묶이지 않는다. 나중에 옮길 일이 반드시 생긴다 |

렌더가 아니어도 된다. `Dockerfile` 은 Fly·Railway·클라우드타입 어디서나 돈다.
`render.yaml` 만 렌더 전용이다.

> ⚠️ **이미지 빌드는 아직 검증되지 않았다.** 개발 환경에 도커 데몬이 없어
> `docker build` 를 돌려보지 못했다. 첫 배포에서 실패하면 그 로그를 보고 고쳐야 한다.
> `node apps/manse-viewer/build.mjs` 와 서버 기동 자체는 검증됐다.

## 사장님이 하실 일

### 1. 렌더 가입

`render.com` → GitHub 계정으로 가입. 카드 등록 필요 (월 $7, 약 1만원).

무료 요금제는 15분 놀면 서버가 잠든다. **심사자가 열었을 때 잠들어 있으면 반려된다.**
그래서 유료로 시작한다.

### 2. 저장소 연결

`New` → `Blueprint` → 이 저장소 선택.
`render.yaml` 을 읽고 서비스를 알아서 만든다.

### 3. 환경변수 채우기

렌더 대시보드의 `Environment` 에서 아래를 입력한다.
**사업자등록증과 글자 하나까지 같아야 한다** — 다르면 심사에서 반려된다.

| 이름 | 넣을 값 |
|---|---|
| `SITE_NAME` | 늘봄사주 |
| `SITE_URL` | https://neulbomsaju.co.kr |
| `BIZ_COMPANY` | 사업자등록증의 상호 |
| `BIZ_REPRESENTATIVE` | 대표자 성명 |
| `BIZ_REG_NUMBER` | 000-00-00000 |
| `BIZ_MAIL_ORDER_NUMBER` | 통신판매업 신고번호 (아직 없으면 비워둠) |
| `BIZ_ADDRESS` | 사업장 소재지 |
| `BIZ_PHONE` | 고객센터 전화 |
| `BIZ_EMAIL` | 고객센터 이메일 |

포트원·API 키 넷은 **나중에** 채운다. 지금 비워두면 심사 대기 모드로 뜬다.

값이 비면 화면에 `[미입력: 상호]` 가 그대로 보인다. 조용한 빈칸이 반려 사유라서
일부러 눈에 띄게 만들어 뒀다.

### 4. 도메인 연결

렌더에서 `Settings` → `Custom Domains` → `neulbomsaju.co.kr` 추가.

그러면 렌더가 **가비아에 넣을 값**을 화면에 띄운다. 그 값을 그대로 복사해서:

가비아 → `My가비아` → `서비스 관리` → 도메인 → `DNS 관리` → 레코드 추가

> 렌더가 주는 값은 계정마다 다르고 가끔 바뀐다. 여기에 적어두면 낡으므로,
> **화면에 뜬 값을 그대로** 쓴다.

DNS는 퍼지는 데 10분~1시간 걸린다. HTTPS 인증서는 렌더가 알아서 붙인다.

### 5. 확인

- `https://neulbomsaju.co.kr` — 사이트가 뜨는가
- `https://neulbomsaju.co.kr/terms` `/privacy` `/refund` — 세 페이지가 뜨는가
- 화면 맨 아래 사업자 정보에 `[미입력: ...]` 이 남아 있지 않은가

### 6. 포트원에 제출

`서비스 URL` 칸에 `https://neulbomsaju.co.kr` 넣고 신청.

## 심사 통과한 뒤

포트원에서 상점 아이디와 채널키가 나오면, 렌더 환경변수에 넷을 채우고 재배포한다.
그 순간부터 결제 버튼이 켜진다. 코드는 안 건드린다.

```
PORTONE_API_SECRET      포트원 관리자 → API 키
PORTONE_STORE_ID        포트원 관리자 → 상점 정보
PORTONE_CHANNEL_KEY     포트원 관리자 → 결제 연동 → 채널
ANTHROPIC_API_KEY       콘솔에서 새로 발급 (이전 키는 폐기됨)
```

## 남은 숙제

- **주문이 메모리에만 있다.** 서버가 재시작되면 사라진다.
  결제를 켜기 **전에** 반드시 Postgres로 바꿔야 한다 — 안 그러면
  "결제했는데 리포트가 사라졌다"가 실제로 발생한다.
  (`MemoryOrderStore`, `MemoryReportCache`)
- 도커 이미지 빌드 미검증.
- 약관·개인정보처리방침·환불정책은 법령을 읽고 쓴 것이지 변호사 검토를 받은 것이 아니다.

# 네이버 블로그 포스팅 — 스타일 가이드 & 생성 프롬프트

대상 블로그: https://blog.naver.com/neulbomlife

네이버는 2020년에 공식 글쓰기 API를 폐지했고, 브라우저 자동화는 계정 정지 위험이 있어
쓰지 않는다. **글과 이미지를 만들어 주면 사람이 직접 복붙해서 올리는 수동 워크플로우**다.
이 문서는 "무엇을 만들어 줄 것인가"의 규격이다.

---

## 1. 분석 근거 (중요)

아래 규칙은 **실제 게시된 글 1편**에서 뽑았다.

> 「구자욱 5안타 2홈런 폭발, 삼성이 한화를 꺾고 8월 첫 연승을 달린 이유」 (2026-08-14 게시)

**한계를 명시해 둔다:**
- 표본이 1편이라, 아래 항목이 *글쓴이의 일관된 습관*인지 *그 글 하나의 우연*인지 구분되지 않는다.
- 게다가 이 글은 원래 봇 세션이 만든 초안이다. 사람이 얼마나 손봤는지 확인되지 않았다.
- **글이 2~3편 더 쌓이면 이 문서를 다시 검증할 것.** 특히 사람이 손댄 부분이 진짜 취향이다.

## 2. 관찰된 스타일

### 제목
```
[인물] [숫자 기록] [강조어], [팀]이 [상대]를 [결과] [의미]한 이유
```
실제 예: `구자욱 5안타 2홈런 폭발, 삼성이 한화를 꺾고 8월 첫 연승을 달린 이유`

- 길이 30~40자
- **숫자 기록을 앞쪽에 배치** (5안타 2홈런) — 눈에 먼저 걸린다
- 쉼표로 앞뒤를 나눔: 앞 = 개인 활약 / 뒤 = 팀 결과
- **`~한 이유`로 마무리** — 궁금증을 남기고, 검색어와도 붙는다
- 팀명 2개 + 인물명 1개 이상을 제목에 넣는다 (검색 유입)

### 본문 구조 — 4문단, 각 2~4문장

| 문단 | 역할 | 실제 글에서 |
|---|---|---|
| 1 | **리드** — 대회 공식명 + 장소 + 대진을 깔고, 결론을 한 문장으로 압축 | "…구자욱의 방망이 하나로 정리됐습니다" |
| 2 | **주인공** — 기록 상세 + 최종 스코어 + 팀 맥락(부진→연승) + 순위 의미 | 8-5 제압, 8월 첫 연승, 리그 2위 |
| 3 | **상대편** — 진 쪽 서사도 반드시 챙긴다 | "한화도 순순히 물러서지는 않았습니다" |
| 4 | **마무리** — 경기에서 끌어낸 일반적 관찰 + 앞으로의 전망 | "…지켜봐야겠습니다" |

3번 문단이 이 스타일의 핵심이다. 승자만 다루지 않고 **패자 쪽 선수 이름을 구체적으로**
(문현빈·강백호·박정현) 적어 준다. 서사 균형도 잡히고 검색 유입도 넓어진다.

### 문체
- **합니다체로 통일** (`~습니다`, `~했습니다`). 해요체·반말 섞지 않는다.
- 한 문장 40~70자. 한 문장에 정보는 두 개까지.
- 스포츠 비유는 쓰되 절제: `신호탄`, `화력`, `무릎을 꿇었습니다`, `각성` 정도.
- 과한 감탄사·이모지 없음. 강조어는 `정말 반가운` 수준까지만.
- 대회명은 **공식 명칭 그대로** 한 번 써 준다 (`2026 신한 SOL KBO리그 정규시즌`).

### 마무리 관습 (빠뜨리지 말 것)
1. 해시태그 6개 — `#대회 #종목 #팀A #팀B #인물 #지역`
2. 출처 고지 한 줄:
   ```
   ※ 이 글은 뉴스 보도(OOO, OOO 등)를 참고해 직접 재구성한 요약글입니다.
   ```
   **이 문장은 저작권상 반드시 유지한다.** 원문 문장을 그대로 옮기지 않았다는 표시다.

### 분량
본문 약 450자(공백 제외). 짧은 편 — 아래 4번 참고.

## 3. 생성 프롬프트 (그대로 복붙해서 사용)

```
아래 기사 정보로 네이버 블로그 글을 써 줘.

[기사 제목]
[기사 요약]
[출처 언론사]

규칙:
- 합니다체로 통일. 해요체·반말 금지.
- 4문단 구성:
  1) 리드 - 대회 공식 명칭과 장소, 대진을 깔고 결론을 한 문장으로 압축
  2) 주인공 - 핵심 기록, 최종 스코어, 팀 상황(연패/연승/순위)의 의미
  3) 상대편 - 진 쪽도 반드시 다루고 선수 이름을 구체적으로 언급
  4) 마무리 - 경기에서 끌어낸 관찰 한 줄 + 앞으로의 전망
- 한 문장 40~70자. 과장된 감탄사와 이모지는 쓰지 말 것.
- 제목: [인물+숫자기록] , [팀 결과]한 이유  형태로 30~40자.
  숫자 기록을 앞쪽에 둘 것.
- 마지막에 해시태그 6개: 대회/종목/팀A/팀B/인물/지역
- 마지막 줄에 반드시:
  ※ 이 글은 뉴스 보도(OOO 등)를 참고해 직접 재구성한 요약글입니다.

지켜야 할 것:
- 기사 원문 문장을 그대로 옮기지 말 것. 사실만 가져와 새로 쓸 것.
- 기사에 없는 기록·수치·발언을 지어내지 말 것.
- 한국 독자 대상이다. 국내 팀/선수가 주인공인 소재만 쓴다.
```

헤더 이미지는 `scripts/make_blog_header.py`로 만든다 (16:9, AI 이미지 대신 SVG 일러스트 —
크레딧 불필요, 저작권 문제 없음).

## 4. 미확정 — 사용자 확인 필요

아래는 **아직 결정되지 않았다.** 다음 세션에서 사용자와 정할 것.

- [ ] **분량을 늘릴 것인가**
      현재 450자. 네이버 검색 노출에는 일반적으로 1,000자 이상이 유리하다고 알려져 있다
      (검증된 수치는 아니고 통용되는 가이드라인). 늘린다면 3번 문단 뒤에
      "경기 흐름" 문단을 하나 더 넣는 방식이 자연스럽다.
- [ ] **소제목을 넣을 것인가**
      현재 글에는 소제목이 없다. 길어지면 필요해진다.
- [ ] **이미지 몇 장을 넣을 것인가**
      현재 헤더 1장. 본문 중간 삽입 위치를 정할지.
- [ ] **스포츠 외 카테고리(정치·사회·경제·연예)도 같은 골격을 쓸 것인가**
      위 4문단 구조는 경기 결과 기사에 맞춰져 있다. 정치·경제 기사에는 3번 문단
      ("상대편")이 성립하지 않을 수 있다.

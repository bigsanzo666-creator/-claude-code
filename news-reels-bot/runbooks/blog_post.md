# 네이버 블로그 포스팅 — 스타일 가이드 & 생성 프롬프트

대상 블로그: https://blog.naver.com/neulbomlife

네이버는 2020년에 공식 글쓰기 API를 폐지했고, 브라우저 자동화는 계정 정지 위험이 있어
쓰지 않는다. **글과 이미지를 만들어 주면 사람이 직접 복붙해서 올리는 수동 워크플로우**다.
이 문서는 "무엇을 만들어 줄 것인가"의 규격이다.

---

## 1. 분석 근거 (중요)

아래 규칙은 **실제 게시된 글 1편**에서 뽑았다.

> 「구자욱 5안타 2홈런 폭발, 삼성이 한화를 꺾고 8월 첫 연승을 달린 이유」 (2026-08-14 게시)

**한계를 명시해 둔다:**
- 표본이 1편이라, 아래 항목이 *글쓴이의 일관된 습관*인지 *그 글 하나의 우연*인지 구분되지 않는다.
- 게다가 이 글은 원래 봇 세션이 만든 초안이다. 사람이 얼마나 손봤는지 확인되지 않았다.
- **글이 2~3편 더 쌓이면 이 문서를 다시 검증할 것.** 특히 사람이 손댄 부분이 진짜 취향이다.

## 2. 관찰된 스타일

### 제목
```
[인물] [숫자 기록] [강조어], [팀]이 [상대]를 [결과] [의미]한 이유
```
실제 예: `구자욱 5안타 2홈런 폭발, 삼성이 한화를 꺾고 8월 첫 연승을 달린 이유`

- 길이 30~40자
- **숫자 기록을 앞쪽에 배치** (5안타 2홈런) — 눈에 먼저 걸린다
- 쉼표로 앞뒤를 나눔: 앞 = 개인 활약 / 뒤 = 팀 결과
- **`~한 이유`로 마무리** — 궁금증을 남기고, 검색어와도 붙는다
- 팀명 2개 + 인물명 1개 이상을 제목에 넣는다 (검색 유입)

### 본문 구조 — 4문단, 각 2~4문장

| 문단 | 역할 | 실제 글에서 |
|---|---|---|
| 1 | **리드** — 대회 공식명 + 장소 + 대진을 깔고, 결론을 한 문장으로 압축 | "…구자욱의 방망이 하나로 정리됐습니다" |
| 2 | **주인공** — 기록 상세 + 최종 스코어 + 팀 맥락(부진→연승) + 순위 의미 | 8-5 제압, 8월 첫 연승, 리그 2위 |
| 3 | **상대편** — 진 쪽 서사도 반드시 챙긴다 | "한화도 순순히 물러서지는 않았습니다" |
| 4 | **마무리** — 경기에서 끌어낸 일반적 관찰 + 앞으로의 전망 | "…지켜봐야겠습니다" |

3번 문단이 이 스타일의 핵심이다. 승자만 다루지 않고 **패자 쪽 선수 이름을 구체적으로**
(문현빈·강백호·박정현) 적어 준다. 서사 균형도 잡히고 검색 유입도 넓어진다.

### 문체
- **합니다체로 통일** (`~습니다`, `~했습니다`). 해요체·반말 섞지 않는다.
- 한 문장 40~70자. 한 문장에 정보는 두 개까지.
- 스포츠 비유는 쓰되 절제: `신호탄`, `화력`, `무릎을 꿇었습니다`, `각성` 정도.
- 과한 감탄사·이모지 없음. 강조어는 `정말 반가운` 수준까지만.
- 대회명은 **공식 명칭 그대로** 한 번 써 준다 (`2026 신한 SOL KBO리그 정규시즌`).

### 마무리 관습 (빠뜨리지 말 것)
1. 해시태그 6개 — `#대회 #종목 #팀A #팀B #인물 #지역`
2. 출처 고지 한 줄:
   ```
   ※ 이 글은 뉴스 보도(OOO, OOO 등)를 참고해 직접 재구성한 요약글입니다.
   ```
   **이 문장은 저작권상 반드시 유지한다.** 원문 문장을 그대로 옮기지 않았다는 표시다.

### 분량
본문 약 450자(공백 제외). 짧은 편 — 아래 4번 참고.

## 3. 생성 프롬프트 (그대로 복붙해서 사용)

```
아래 기사 정보로 네이버 블로그 글을 써 줘.

[기사 제목]
[기사 요약]
[출처 언론사]

규칙:
- 합니다체로 통일. 해요체·반말 금지.
- 본문 1,000자 이상.
- 5문단 구성:
  1) 리드 - 대회 공식 명칭과 장소, 대진을 깔고 결론을 한 문장으로 압축
  2) 주인공 - 핵심 기록, 최종 스코어, 팀 상황(연패/연승/순위)의 의미
  3) 경기 흐름 - 득점 흐름, 분위기가 바뀐 시점, 투수 운영이나 교체
  4) 상대편 - 진 쪽도 반드시 다루고 선수 이름을 구체적으로 언급
  5) 마무리 - 경기에서 끌어낸 관찰 한 줄 + 앞으로의 전망
- 소제목을 2~3개 넣을 것. 문단마다 붙이지 말고 본문을 2~3덩어리로 묶어 그 앞에 단다.
- 한 문장 40~70자. 과장된 감탄사와 이모지는 쓰지 말 것.
- 제목: [인물+숫자기록] , [팀 결과]한 이유  형태로 30~40자.
  숫자 기록을 앞쪽에 둘 것.
- 마지막에 해시태그 6개: 대회/종목/팀A/팀B/인물/지역
- 마지막 줄에 반드시:
  ※ 이 글은 뉴스 보도(OOO 등)를 참고해 직접 재구성한 요약글입니다.

- 본문에 넣을 카드뉴스 2~3장의 문구도 같이 뽑아 줘.
  한 장에 메시지 하나, 짧고 굵게. 본문에서 핵심 문장을 가져와 압축할 것
  (새로 쓰지 말 것). 각 카드가 본문 어느 위치에 들어가면 좋을지도 표시해 줘.

지켜야 할 것:
- 기사 원문 문장을 그대로 옮기지 말 것. 사실만 가져와 새로 쓸 것.
- 기사에 없는 기록·수치·발언을 지어내지 말 것.
- 분량을 채우려고 같은 말을 반복하지 말 것. 새 정보가 없으면 늘리지 말 것.
- 한국 독자 대상이다. 국내 팀/선수가 주인공인 소재만 쓴다.
```

헤더 이미지는 `scripts/make_blog_header.py`로 만든다 (16:9, AI 이미지 대신 SVG 일러스트 —
크레딧 불필요, 저작권 문제 없음).

## 4. 확정된 규격 (2026-08-15 사용자 결정)

| 항목 | 결정 |
|---|---|
| 분량 | **1,000자 이상** (기존 450자에서 확대) |
| 소제목 | **넣는다** (분량이 늘어나므로 필수) |
| 이미지 | **헤더 1장 + 본문 2~3장** |
| 카테고리 | **스포츠만.** 정치·사회·경제·연예는 블로그에 올리지 않는다 |

### 1,000자로 늘리는 방법
2번(주인공)과 3번(상대편) 사이에 **"경기 흐름"** 문단을 추가한다.
득점 흐름, 분위기가 바뀐 이닝/시점, 교체나 투수 운영 같은 전개를 다룬다.
문단을 억지로 늘려 같은 말을 반복하지 말 것 — 새 정보가 없으면 늘리지 않는다.

### 소제목
문단마다 붙이지 말고 **본문을 2~3덩어리로 묶어** 그 앞에 단다.
예: `구자욱, 혼자서 경기를 뒤집다` / `한화의 홈런 세 방도 부족했다` / `삼성의 남은 일정`

### 카테고리를 스포츠로 한정한 이유
2번 항목의 4문단 골격은 **경기 결과 기사 전용**이다. 3번 문단("상대편")이
정치·경제 기사에는 성립하지 않는다. 나중에 넓힌다면 카테고리별 골격을 따로 설계해야 한다.
(인스타그램 캐러셀은 5개 카테고리를 그대로 유지한다 — 블로그만 스포츠로 좁힌 것)

## 5. 블로그 카드뉴스

본문 이미지 2~3장은 **카드뉴스 형태**로 만든다. 이미 있는 인스타 캐러셀 파이프라인
(`make_carousel_html.py`)을 그대로 재사용하면 되므로 새로 만들 게 거의 없다.

### 벤치마크
- **`prompt_what`** — 사용자가 2026-08-14에 보내준 참고 인스타 계정. 캐러셀 형식.
  애초에 릴스 대신 캐러셀로 방향을 정한 근거가 된 계정이므로, 규격을 정할 때 이걸 먼저 볼 것.
- 뉴스를 카드뉴스로 만드는 계정들(스브스뉴스, 14F 등)도 목적이 같아 참고할 만하다.
  상품 홍보용 카드뉴스 가이드는 CTA 구조가 달라서 그대로 적용되지 않는다.

### 구성 원칙
- **한 장에 메시지 하나.** 글자는 짧고 크게 (모바일에서 읽혀야 한다)
- 첫 장: 강한 제목 + 짧은 부제 + 핵심 키워드 + 브랜드명
- 색은 2~3가지로 통일하고, 제목과 본문의 크기 차이를 분명히 둔다
- 블로그 본문에서 **핵심 문장을 뽑아** 카드로 옮긴다 (새로 쓰지 말고 압축)

### ⚠️ 비율 문제 — 먼저 해결할 것

현재 `make_carousel_html.py`는 **1080×1920 (9:16)** 으로 렌더링한다 (`W, H = 1080, 1920`).
이건 스토리/릴스 비율이다.

- **인스타그램 피드 캐러셀은 4:5(1080×1350)까지만 지원한다.** 9:16을 올리면 잘린다.
  카드가 `상단 58% 사진 / 하단 40% 텍스트` 구조라, 잘리면 텍스트가 손상될 수 있다.
- 아직 인스타 실게시를 한 번도 안 해봐서 이 문제가 드러나지 않은 상태다.
- 블로그 삽입용으로는 3:4(1080×1440)가 읽기 좋다고 알려져 있다.

**권장**: `W, H = 1080, 1350` (4:5)으로 바꿔서 **한 벌로 블로그와 인스타 양쪽에 쓴다.**
비율을 바꾸면 폰트 크기와 58%/40% 영역 비율도 같이 조정해야 하므로,
바꾼 뒤 반드시 렌더링 결과를 눈으로 확인할 것.

※ 인스타그램이 허용하는 비율은 정책이 바뀔 수 있으니, 실게시 시도할 때 실제 응답으로
확인할 것. 위 4:5 수치는 통용되는 규격 기준이다.

### 역할 분담
| 매체 | 역할 |
|---|---|
| 블로그 글 | 자세한 설명. 검색으로 유입되는 통로 |
| 카드뉴스 | 핵심만 짧게. 블로그 본문 중간에 삽입 |
| 인스타 캐러셀 | 같은 카드를 SNS로 확산 |

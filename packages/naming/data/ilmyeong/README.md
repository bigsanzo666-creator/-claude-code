# 인명용 한자표 옮겨 적기

대법원 「인명용 한자표」(2007. 8. 기준 PDF, 54쪽)를 한 쪽씩 눈으로 읽어
옮겨 적는 중이다. 쪽 번호가 곧 파일 이름이다. `01.json` ~ `54.json`.

한 줄은 표의 한 칸이다.

```json
{ "k": "독음", "base": "한문 교육용 기초한자", "a1": "별표1", "a2": "별표2 괄호 안" }
```

## 안전 장치

옮겨 적은 글자는 모두 검사를 거친다. 그 글자의 유니코드 한국 독음이
그 줄의 독음과 맞아야만 남긴다. 첫소리 ㄴ·ㄹ 은 ㅇ·ㄴ 으로도 읽을 수
있으므로(대법원 규칙) 그것까지 맞춰 본다. 걸린 글자는 고치거나 버린다.

**버리는 쪽이 안전하다.** 있어야 할 글자를 빠뜨리면 이름 후보가 몇 개
줄어들 뿐이지만, 없는 글자를 넣으면 출생신고가 반려된다.

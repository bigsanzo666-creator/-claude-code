# 광고

영상을 손으로 만들지 않는다. **대본에 한 칸을 적으면 영상이 나온다.**

## 세 개뿐이다

| 파일 | 하는 일 |
|---|---|
| `대본.ts` | **여기만 고친다.** 첫 문장, 어느 신령 영상, 어느 상품으로 보낼지 |
| `verify.ts` | 만들기 전에 검사한다. 거짓말·겁주는 말·없는 영상을 잡는다 |
| `만들기.ts` | 실제로 영상을 뽑는다 |

## 쓰는 차례

```
node --experimental-strip-types 광고/verify.ts        ← 먼저 검사
node --experimental-strip-types 광고/만들기.ts        ← 대본에 있는 것 전부
node --experimental-strip-types 광고/만들기.ts A_dasi ← 한 편만
node --experimental-strip-types 광고/만들기.ts --길이 30  ← 쇼츠용으로 늘려
```

나온 것은 `광고/완성/` 에 떨어진다. 1080×1920 세로, 소리 있음.
인스타 릴스·유튜브 쇼츠·틱톡·네이버 클립에 그대로 올라간다.

**검사가 빨간불이면 영상을 만들지 마라.** 영상은 한 번 올리면 주워 담기 어렵다.

## 누구에게 파는가

온라인 사주를 제일 많이 쓰는 사람은 10대 후반~20대 후반 여성이고,
**실제로 돈을 내는 사람은 26세 이상 여성**이 압도적이다.

다만 값이 큰 상품은 30대가 산다. 그래서 겨냥을 둘로 나눈다.

| | 나이 | 상품 |
|---|---|---|
| 들어오는 문 | 여성 25~34세 | 연애·재회·궁합·돈그릇 |
| 돈 되는 문 | 여성 29~42세 | 작명·택일·명절 |

## 첫 문장 쓰는 법

**질문하지 마라. 혼잣말을 적어라.**

- ✗ 「당신의 연애운이 궁금하신가요?」 — 광고처럼 들린다. 손이 지나간다
- ○ 「이번엔 다를 줄 알았는데」 — 자기 이야기다. 손이 멈춘다

검사가 물음표로 끝나는 첫 문장을 막는다.

## 적으면 안 되는 것

- **「무료」·「0원」은 실제로 값을 받지 않는 것에만.**
  여덟 글자·오행·대운, 그리고 꿈해몽뿐이다. 유료 상품 옆에 적으면
  표시광고법상 거짓·과장광고다. 검사가 이걸 본다.
- **값을 광고 글에 적지 않는다.** 값은 `packages/commerce/src/catalog.ts`
  한 곳에서만 온다. 광고에 적어 두면 값이 오를 때 거짓말이 된다.
- **겁주지 않는다.** 「큰일 난다」·「막혔다」·「지금 안 보면」. 사이트에서 안 쓰는
  말을 광고에서 쓰면 들어와서 실망한다. 그게 환불로 돌아온다.

## 아는 함정

### 원본 오른쪽 아래에 만든 도구 이름이 찍혀 있다

신령 영상 구석에 글자가 있다. 광고에 보이면 안 되므로 6% 당겨서 위쪽 기준으로
잘라낸다. **새 영상을 넣을 때 이 구석을 먼저 봐라.**

### 글씨를 크롬으로 찍는다

ffmpeg 에도 글씨 기능이 있지만 이 기계에 한글 글꼴이 없어 네모가 나온다.
크롬으로 투명한 그림을 찍어 얹는다. 덤으로 사이트와 같은 글꼴·같은 금색이 된다.

### 돈 쓰는 차례

1. **0원 · 2~3주** — 네 군데에 그냥 올린다. 일주일에 세 편.
   어느 첫 문장이 먹히는지 공짜로 알아낸다.
2. **터진 한 편에만 10만원 · 7일** — 인스타만. 목표는 결제가 아니라
   **무료 사주를 끝까지 본 사람**으로 잡는다. 결제는 너무 드물어 학습이 안 된다.
3. **그 사람들한테만 다시** — 돈은 여기서 벌린다.

1만 5천원으로는 아무것도 알아낼 수 없다. 광고 하나가 일주일에 성과 50건쯤
쌓여야 비로소 누구에게 보일지 배운다. 그 아래로는 그냥 아무한테나 뿌린다.

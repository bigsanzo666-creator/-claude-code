# 광고 영상

사이트가 이미 가진 신령 영상에서 잘라 만든 것이다. 새로 그린 그림이 없으므로
사이트와 생김새가 어긋나지 않는다.

## 늘봄사주_광고A.mp4

20초 · 1080×1920 (세로) · 24fps · 소리 있음. 릴스·숏폼 그대로 올라간다.

| 시간 | 자막 |
|---|---|
| 0~3초 | 사주, 돈부터 내지 마세요 |
| 3~6초 | 먼저 **무료로** 봐 드립니다 |
| 6~9.5초 | 타고난 **여덟 글자** · 오행과 대운까지 · 0원 |
| 9.5~13초 | 간밤에 꾼 **꿈**도 · 0원 |
| 13~16.5초 | 더 깊이 보고 싶으실 때 그때 고르시면 됩니다 |
| 16.5~20초 | 늘봄사주 · neulbomsaju.co.kr |

### 지킨 것

- **없는 말을 하지 않는다.** 「무료」라고 적은 것은 실제로 값을 받지 않는
  것들뿐이다 — 여덟 글자·오행·대운, 그리고 꿈해몽. 표시광고법상 거짓·과장광고가
  되지 않으려면 광고 문구도 코드와 같은 말을 해야 한다.
- **원본의 「Veo」 글자를 지웠다.** 영상 오른쪽 아래에 만든 도구 이름이 찍혀
  있었다. 6% 확대해 위쪽 기준으로 잘라냈다. 새 영상을 쓸 때도 이 구석을 먼저 본다.
